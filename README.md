Download an exe below and run it. No install needed.

Versions 1.0.0 to 1.0.6 are hotfixed builds: same features as the original, plus the macro input fix, a working updater and the fullscreen start, so you can always update again from them.

## Already have Pulse?

Open **Settings > Updates > Install another version** to switch to any version above, or go back to the newest one. Updates are checked against SHA-256 checksums before they are installed.

## SHA-256 checksums

See `checksums.json` in this repo (latest and hotfixed builds).

Every version's full changelog is in the commit history: each version is one commit titled with its version number.
