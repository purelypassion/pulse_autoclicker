# Pulse - autoclicker & macro studio for Windows

Download an exe below and run it. No install needed.

Older versions (1.0.0 to 1.0.6) are hotfixed builds: same features as the original, plus the macro input fix, a working updater and the fullscreen start, so you can always update again from them.

## Already have Pulse?

Open **Settings > Updates > Install another version** to switch to any version above, or go back to the newest one. Updates are checked against SHA-256 checksums before they are installed.
